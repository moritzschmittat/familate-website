# familate-website

The public website at https://familate.com: home page, privacy policy and support.

Plain HTML and CSS, no build step. GitHub Pages publishes the `main` branch on every push.

- `index.html` home page
- `privacy.html` privacy policy
- `support.html` help and account deletion
- `styles.css` shared styles
- `assets/` logo and fonts (Outfit and DM Sans, SIL Open Font License)
